# Greenly — A Greener Egypt
موقع توعوي عربي متجاوب عن حماية البيئة في مصر.

## التشغيل
افتح `index.html` في المتصفح. الصور الخارجية تحتاج اتصالًا بالإنترنت.

## النشر مجانًا على GitHub Pages
1. أنشئ مستودع GitHub عام (Public).
2. ارفع `index.html` إلى جذر المستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
5. انتظر رابط الموقع الذي يعرضه GitHub Pages.

## الوظائف الموجودة
- قائمة تنقل متجاوبة.
- أقسام نصائح بيئية، مياه، طاقة ونفايات.
- حاسبة توفّر مياه تقديرية.
- اختبار معلومات بيئية تفاعلي.
- وضع إضاءة بديل.
