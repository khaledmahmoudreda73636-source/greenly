# Green Egypt website
موقع عربي تجريبي متجاوب مستوحى من التصميم المرفق.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو أي متصفح حديث.
3. اضغط على روابط القائمة للتنقل بين الصفحات.

## المميزات
- الرئيسية، البيئة، توفير الموارد، اختبار معلوماتك، المشروعات، عن المشروع.
- حاسبة تقديرية للمياه والكهرباء.
- اختبار تفاعلي مع حساب النتيجة.
- أزرار تفاصيل المشروعات، تصميم متجاوب للموبايل والكمبيوتر.

ملاحظة: صور المشروعات وصورة الغلاف يتم تحميلها من الإنترنت، لذلك قد لا تظهر دون اتصال.
